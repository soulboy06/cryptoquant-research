# 第二阶段消融实验报告：纯动态 C2 出场下的多预测周期析因检验

## 1. 实验目标与科学问题

在 Phase 2 初步实验中，我们将预测周期 $H$ 与最大持仓时间绑定为 $\text{max\_holding\_hours} = 2 \times H$。
为了排除“持仓时间被动拉长”对收益的干扰，本消融实验**将所有预测周期的退出机制 100% 保持为原版的纯动态 C2 出场**（`max_holding_hours = None`，无任何持仓时限截断；浮盈达到 +1.2% 激活动态保本，之后若回落至成本价 +0.25% 则触发退出；8% 硬止损；信号退出）。

**本实验旨在精准回答核心科学问题**：
> 到底是**“预测周期变长”**害死了收益，还是**“持仓时间变长”**害死了收益？

## 3. 核心因果归因与客观分析

实证数据显示：

### 现象一：预测周期拉长本身导致信号质量严重恶化
- 观察全部使用原版纯动态 C2 出场（完全排除持仓时限干扰）的对比：
  - 4h: **+0.1293% / week**
  - 8h: **+0.0912% / week**
  - 12h: **+0.0015% / week**（收益直接坍塌为零）
  - 24h: **+0.0014% / week**（收益直接坍塌为零）
- **客观事实**：即使完全不设持仓时限，只要将预测目标拉长至 12h 或 24h，年复合收益率就从 +6.95% 跌至 +0.07%，几乎归零。
- **机制机理**：
  1. **正样本基率虚高（45.62%）**：24h 周期下，随机波动跨越 0.30055% 的概率接近抛硬币，导致分类器发出极多假买入信号，交易次数暴增至 536 笔；
  2. **交易周转增加与摩擦成本放大**：24h 总成交额激增至 25,865 USDT，累计产生 25.87 USDT 手续费（4h 仅 10.69 USDT），高频摩擦显著削弱了微薄的利润；
  3. **特征与周期效用**：在当前特征、模型、标签和执行体系下，12h/24h 的样本外预测/交易效用明显弱于 4h。

### 现象二：持仓时限在不同周期下的表现差异
- **在短周期（4h、8h）上**：纯动态 C2 明显优于机械时限强平（4h 下纯 C2 的 +0.1293% 优于 8h 强平的 +0.1033%），说明原版 C2 依靠动态保本能够更好地保护右侧趋势的长尾利润；
- **在长周期（12h、24h）上**：纯 C2 与机械时限两者的收益均已严重恶化。在 12h 上，24h 强平为 +0.0042%，略微高于纯 C2 的 +0.0015%；在 24h 上，死扛至 48h 会因市场震荡而加剧尾部亏损（2025 年亏损从 -7.21% 扩大至 -12.33%）。但两组配置均已实质性失格。

## 4. 终审定论与剪枝

1. **科学事实已彻底查明**：
   - 预测周期的最有效颗粒度确定为 **4h**；
   - 无论是否添加持仓时限，长预测周期（12h、24h）的信号质量均发生实质性崩溃；
   - 纯动态 C2 出场机制在优质信号（4h）下表现最优。
2. **决策固化（D-048 证据完备）**：
   - 预测周期方向正式结项并彻底剪枝，周期严格冻结为 **4h**，出场机制保持 **纯动态 C2**；
   - 坚决不再任何预测周期或持仓时限上刷微观参数，全力保护研究算力。
