## 五、原 Fitness 函数专门检查

代码定位：`src/cryptoquant/optimization/engine.py` 行 191～204。

```python
def calculate_fitness_score(
    g_week: float | None,
    worst_mdd: float,
    ret_2025: float,
    min_cycles: int,
    floor_triggers: int,
) -> float:
    g_pct = float(g_week) * 100 if g_week is not None else -999.0
    dd_penalty = max(0.0, worst_mdd - 0.05) * 50.0  # MDD > 5% 后的惩罚
    ret25_penalty = max(0.0, -ret_2025) * 50.0       # 2025 年亏损惩罚
    cycle_penalty = 10.0 if min_cycles < 30 else 0.0
    floor_penalty = 100.0 if floor_triggers > 0 else 0.0
    return g_pct - dd_penalty - ret25_penalty - cycle_penalty - floor_penalty
```

### 1. 权重与惩罚阶梯核算
- **$g_{week}$ 奖励权重**：`1.0`（将周净收益乘以 100，+0.1293% 周收益对应 0.1293 分）；
- **MDD 惩罚起点与斜率**：从 `worst_mdd > 5%` 开始，每超出 1% 扣除 **0.50 分**（惩罚斜率 50.0）；
- **2025 亏损惩罚**：只要 2025 年亏损，每亏损 1% 扣除 **0.50 分**（惩罚斜率 50.0）；
- **样本周期惩罚**：若任意年份闭合周期 $<30$ 笔，直接巨额扣除 **10.0 分**（一票否决门槛）；
- **底线触发惩罚**：发生本金底线触发，直接扣除 **100.0 分**。

### 2. 核心量化启示：为什么 Champion 不是 Fitness 第一名？
原 fitness 函数的人工偏好是**极度厌恶风险**（MDD 惩罚与 2025 亏损惩罚的敏感度是周收益奖励的 **50 倍**！）。
- OPT-0056 的周收益虽然落后 OPT-0026 达 2.69 bps（0.1024% vs 0.1293%）；
- 但其 2025 收益少亏 0.26%，回撤低 0.30%，在 50 倍放大后挽回了 $0.26\% \times 50 + 0.30\% \times 50 = 0.28$ 分，使得 OPT-0056 的 fitness（-4.22）战胜了 OPT-0026（-4.47）。

> **终审结论**：
> **后续选择 OPT-0026 作为基准，明确说明决策层在实际操作中并未机械遵循原 fitness 公式，而是人工放宽了对 2025 年小幅回撤的惩罚，换取更高的周收益（+0.1293%）和 2024 年跨越 15% 的进攻性。**

## 七、选拔偏差与“赢家诅咒”（Selection Bias & Winner's Curse）

必须明确承认以下方法论局限：
1. **2023、2024、2025 已属充分暴露的研究开发集（In-Sample Development Data）**：
   - 200 组参数搜索全量在 2023～2025 上运行并据此选拔；
   - OPT-0026 正是从该数据集的 200 次试验中涌现出的 Pareto 赢家；
2. **后续 Phase 击败 Challenger 的赢家诅咒**：
   - 在后续 Phase 1、2、3、4A、4B、4B2 中，所有受控变体同样是在这三年历史上与 OPT-0026 竞争；
   - OPT-0026 在开发集上已经处于局部前沿极值，任何单维度的扰动（如强行调高阈值、改成树模型、横截面砍掉一币）在样本内出现性能劣化是大概率事件；
   - **不能将“受控变体在开发集上未能击败 OPT-0026”等同于“OPT-0026 是全局真实 Alpha 极限”**。这混入了不可忽视的 Selection Bias。

## 八、后续研究的路径依赖审计（Phase 1～4B2）

对后续连续 6 轮受控实验的结构进行审视：

2. **单变量受控消融（Single-Variable Ablation）的威力与局限**：
   - **科学有效性**：单变量控制完美分离了因果效应（例如 Phase 4B 证明了仅淘汰币种直接留现金会踏空，Phase 4B2 证明了 Rank 1 重分配会遭遇短线反向选择）；

   - **它无法证明**：“不存在由新特征、不同入场阈值和全新出场逻辑构成的多维联合协同解”。
