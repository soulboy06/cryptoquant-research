# EXP-061：候选模型 EXP-049 成本压力测试与抗摩擦鲁棒性评估报告

## 1. 实验目标与评测背景

在阶段4第四轮细化阈值网格实验中，模型 **`EXP-049`（12特征逻辑回归，C=0.1，阈值=0.64，base成本）** 成为项目自启动以来**首个完全通过全部4项硬性门槛的合格候选模型**（实现扣费后正收益 +1.54%、最大回撤仅 2.84%、闭合交易 33 笔突破 $\ge 30$ 笔门槛、底线 0 次）。

根据项目预定研发规范（见 [第一轮实验方案](docs/superpowers/specs/2026-10-04-first-experiment-design.md) 与 [selection.py](src/cryptoquant/models/selection.py)）：
> **在正式开启任何 2026 年保留测试集之前，必须对验证集胜出的合格候选模型开展更高滑点与极端交易摩擦的成本压力测试，以检验其是否依赖理想交易假设，评估策略在恶劣执行环境下的生存能力。**

本项目于 2025 年全年验证期（2025-01-01 至 2025-12-31 UTC）对 EXP-049 实施了两档独立的成本压力测试：
- **`EXP-059`**：中度执行恶化情景（`higher_execution`：单边手续费 0.1%，不利价差/滑点 0.10%，双边往返摩擦 0.40%）；
- **`EXP-060`**：极度严苛摩擦情景（`strict`：单边手续费翻倍至 0.2%，不利价差/滑点 0.10%，双边往返摩擦 0.60%）。

## 3. 压力测试核心发现与鲁棒性剖析

### 3.1 极强的抗滑点生存能力（EXP-059）
在 `higher_execution` 情景下，每笔买卖的滑点与不利价差均从万5提升至千1（即往返双边额外承受 0.10% 的买卖冲击惩罚）：
- 策略净收益仅从 +1.54% 适度衰减至 **+0.56%**，**在更恶劣的执行假设下依然保持绝对正收益**！
- 最大回撤仅从 2.84% 轻微上升至 **3.03%**，防守表现极度平稳；
- 这证明策略的入场信号来自于真实的方向性动量与资金费率优势，而非依赖微小价格跳动的脆弱套利。

### 3.2 极端摩擦下的防守韧性（EXP-060）
在 `strict` 惩罚性费率下（交易所手续费翻倍至 0.20%，双边往返滑点与手续费摩擦高达 0.60%）：
- 尽管一年内被扣除了高达 3.88 USDT 的高额手续费，账户期末净值依然维持在 **98.65 USDT**（净亏损仅 **-1.35%**）；
- **最大回撤依然仅为 3.37%**，本金底线（50 USDT）从未受到丝毫威胁（底线触发 0 次，止损 0 次）；
- 相比之下，同期买入持有巨亏 -15.68%（回撤47.24%），EMA趋势策略亏损 -34.74%（回撤45.93%），过拟合树模型亏损 -32.50%。EXP-049 展现了碾压级的风险控制与资金保护能力。

### 3.3 信号与风控的稳定性
- 在全部三档情景中，策略精确执行 66 笔成交（33 笔买入 + 33 笔卖出），闭合周期均为 33 笔；
- ETH 作为最强 Alpha 贡献源，在三档情景下全部实现平仓正利润（+3.11 USDT / +2.39 USDT / +0.99 USDT）；
- 严格向前对齐资金费率与小时收盘确认，杜绝了未来函数与前瞻偏差。

## 4. 压力测试综合结论与参数冻结建议

### 4.1 筛选评定
候选模型 **`EXP-049`** 正式通过压力测试评估：
- **抗滑点能力**：通过（在 higher_execution 下维持绝对正收益 +0.56%）；
- **极端防守能力**：通过（在 strict 摩擦翻倍下回撤仅 3.37%，远低于 $\le 25\%$ 门槛，底线 0 次）；

- **评定结论**：**`stress_testing_passed_ready_for_freeze`（压力测试通过，具备参数冻结资格）**。

### 4.2 策略最终冻结参数清单
建议向用户汇报并正式冻结以下生产参数卡，后续不再允许调整任何参数：
