# 第七轮：简单市场状态买入过滤方案

日期：2026-10-05（Asia/Shanghai）；版本 v0.1。

状态：方案文档审查通过，研究默认值已明确；方向由用户D-033与“按你的来”确认，用户后续“开始”授权实施。实际代码／检查／实验进度统一看STATUS；文档通过不代表代码或策略验收，本方案数值未因实施而调整。

## 1. 研究问题与范围取舍

现有 C2 的 base W1／W2／R2025 净收益约 +4.24%／+26.62%／-12.91%。年份差异不能证明亏损由弱趋势导致；本轮检验一个假说：**在可观察的 BTC 弱趋势或下行状态限制三币买入，能否改善跨窗扣费收益和回撤？**

候选实现方式有：逐币状态过滤、BTC 共同市场过滤、同时加入多状态阈值／仓位响应。第一版选择 BTC 共同市场过滤：只新增一个共同决策条件，避免三个币分别选阈值；代价是可能错过 ETH／SOL 独立行情。逐币状态、动态阈值和降仓留到下一轮分别检验。

与 D-033 的 R0—R3讨论框架相比，本轮先冻结 R0／R1 两组；R2／R3 未启动，不预先实现多个响应。这样既满足市场过滤优先，也控制候选搜索和账户实验数量。

## 2. 固定基线与可用数据

- C2：三币独立逻辑回归、12项原预测特征、net_positive_base_v1、C=0.1、T=0.50；只预测，不重新拟合、不向模型添加状态特征。
- 100 USDT 共用虚拟账户、50固定底线、单币目标上限30%、8%硬止损、原 C2 1.20%激活／average_cost×1.0025监控线、4h冷却及决策时钟保持一致。
- W1／W2／R2025 时间边界沿用固定研究窗口，模型分别复用 EXP-065／067／094。执行前现场核对政策与来源，编号引用不替代清单校验。
- 行情使用 EXP-003 已核验的 development／validation 和连续历史；资金费率仅 EXP-063 截断快照。禁止读取2026测试行情与原始未截断 funding 文件。
- 2023、2024、2025均为研究／选择数据，不能称全新盲测。保持各窗独立100起始，跨窗几何合成不是一条连续账户曲线。

## 3. 状态规则与时间定义

状态只来自 BTC 已收盘小时 OHLC，不使用当前小时的 high／low／close、未来收益或标签。整点 t 的输入最多至 open_time=t−1h、available_time=t；每4h决策点读取此时状态，买入发生在 t 的现有开盘执行流程。

指标固定为：

- ADX14：使用小时 TR 与正负方向运动，Wilder 平滑周期14；平滑初值为首14个有效 TR／DM 的算术平均，之后 `rma=(13*prev+x)/14`。DI分别为100×平滑DM／平滑TR，DX为100×abs(DI+−DI−)／(DI++DI−)，ADX初值为首14个有效DX均值，再按同一递推。TR或DI分母为0时，对应DI／DX定0；缺失不能定0。
- EMA72：首72个连续有效收盘均值作种子，此后 alpha=2/73；`slope24=EMA72(t)/EMA72(t−24h)−1`。
- **允许买入**：ADX14≥20 且 slope24>0；其他有效状态统称“受限”，不声称这是市场真实类别或最优阈值。
- 发生已核验 halt／no_trade 时连续指标段重置；只有连续744个已收盘有效小时且指标有限时状态才有效。预热中的无效状态阻止 R1 买入，不阻止风险退出。未知缺口、非法价格或冲突时间戳使状态准备／账户运行失败并保留证据，不得标作无效状态后静默继续。

这些阈值是预定研究默认值，只跑一个组合，不搜索 ADX／EMA 参数；ATR、BTC24/72h收益等本轮不加入决策条件。

状态输出独立表：decision_time、available_time、BTC ADX14、EMA72、slope24、history_count、state_valid、allow_buy。与模型概率表分离，列名白名单避免把未来标签传入交易层。

许可表须完整覆盖账户全部4h决策点且无多行、缺值或重复；无效状态必须allow_buy=False，冲突或不完整输入失败，不能默认放行或沿用上次许可。只有明确关闭许可过滤才沿用R0。

## 4. R0／R1行为与已有持仓

| 候选 | 买入 | 卖出与已有持仓 |
| --- | --- | --- |
| R0 | 现有C2原样 | 现有C2原样 |
| R1 | 当共同市场状态受限／无效时，禁止三币任何 BUY，包括新开仓和补仓；状态允许时沿用原目标及风险资格 | 仍用原概率生成目标、原账本制定 SELL；状态变化本身不清仓、不触发新止损、不更改冷却 |

过滤位置为**原先卖后买流程中的买单许可**：原风控退出和策略卖单优先执行；受限时记录 BUY 拒绝原因 `regime_blocked`。不能简单把目标权重改0，因为那会同时强制卖出，将入场过滤变成另一套出场规则。

当前模型信号即使持续为正仍可能发生目标仓位再平衡，R1阻止受限时的增持，但允许按原规则减持；该差别必须在日志中保留。已有C2的手续费、最小金额、尾差、现金缩放、冷却和固定底线不修改。

## 5. 有限账户矩阵与来源复用

1. 只读核对已有 C2 三窗 base（EXP-108／109／110）与两档压力（EXP-115—120）的完整来源和配置；作为 R0 对照，不重跑9个旧账户。
2. 新增 R1×三窗×base，共3个独立账户；提前登记唯一编号，失败不覆盖。原模型及数据不重新准备。
3. 按下节基础门槛选择。若没有合格候选，完整记录失败并结束，不继续压力搜索。
4. 只有R1合格时，R1×三窗×higher_execution／strict，共6个独立账户；先冻结选择清单与SHA再执行。
5. 最多9个新账户尝试（失败也计入），另有1组状态准备、1组选择、1组比较，最多12个新登记；编号开始前从登记表核对，不在本草案假定下一号。修复失败需新号并占预算，超额须新决策，不能绕过。

若现有R0来源无法核验或执行算法变化影响其可比性，先停止新账户并修复／另定基线预算，不能默默重跑或替换对照。允许用合成输入检查关闭过滤与原C2逐笔一致，但不声称合成检查证明全年结果完全相同。

## 6. 冻结评价标准

### 6.1 基础筛选

所有 R1 base 窗口须满足底线0次、闭合周期≥30、最大回撤≤25%；不足30判证据不足，不代表统计显著性。

并同时满足：

- W1净收益>0；W2净收益≥20.00%。
- R2025净收益高于对应 R0，且最大回撤低于 R0；三窗合成 g_week 高于 R0。
- W1／W2回撤不超过对应 R0 +1.5个百分点。

R2025净收益>-5%是更高的改善目标，单列是否达到，不以未达到时改写筛选门槛。交易次数、费用和按币表现全部报告；少交易／少费用本身不判成功。保留全部止损及未成交记录，不能通过事后删除亏损证明正期望。

### 6.2 压力评价

沿用第六轮明确标准：higher W1≥1%、W2≥20%、W1/W2回撤≤9%；strict W1≥−1%、W2≥15%、W1/W2回撤≤10%；每窗底线0、周期≥30。R2025两档净收益与同成本 R0 C2 比较，要求更高且回撤不更大。精确数值判定，禁止四舍五入越线。

第六轮 strict W2 原失败不因新结果而改为通过；第七轮自身不过线也如实判失败。

### 6.3 三层结论

分别报告：输入来源及接口验收是否通过；有限历史是否观察到相对改善及代价；是否达到长期几何平均周净收益1.5%目标。三窗合成目标判定与各窗净收益／strict盈利／回撤及样本量同时给出，单年牛市成绩不能代替长期目标。即使过线，也没有新独立样本外或实时模拟证据，不开启2026或真实交易。
