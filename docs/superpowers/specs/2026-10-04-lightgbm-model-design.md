# 第三轮实验方案：引入轻量级非线性树模型（LightGBM）

最后更新：2026-10-04（Asia/Shanghai）

## 1. 背景与改进动因

在第一轮（EXP-008—020）与第二轮（EXP-021—034）实验中，我们建立了基于小时线收盘信号、扣除0.15%双边交易摩擦、100 USDT共用本金与固定50 USDT底线的量化模拟验证系统。

两轮实验在2025年（全年深幅回调与剧烈震荡市，买入持有基准跌-15.68%，最大回撤47.24%）的独立盲考中揭示了明确的规律：
1. **资金费率与动量特征具备显著的预测价值**：在0.65高概率阈值下，模型在熊震市中取得了 +1.20% ~ +1.87% 的绝对正收益，且最大回撤仅 2.58% ~ 2.84%，ETH等币种表现尤为稳定；
2. **线性模型的表达能力瓶颈**：逻辑回归本质上是广义线性模型（对12维特征进行固定线性加权），无法表达多特征之间的**非线性条件组合**（例如：“短期均线超跌 + 资金费率出现深度负溢价空头挤压”是胜率极高的反弹信号；而“均线超跌 + 资金费率依然过热”则往往是加速下跌）。
3. **阈值两难困境**：
   - 阈值设为0.65时，出击极准、胜率极高，但全年仅22~24笔闭合交易周期，差6~8笔未达预设的 $\ge 30$ 笔统计显著性硬门槛；
   - 阈值放宽至0.60时，交易周期达91~95笔，但混入了大量“平庸特征线性相加”的微弱信号，被0.15%的双边手续费侵蚀，导致年化亏损 -5.68% ~ -7.15%。

为突破线性模型的瓶颈，根据决策 [D-025](file:///d:/量化/DECISIONS.md)，第三轮改进将分类器升级为轻量级梯度提升决策树（**LightGBM**）。

## 2. LightGBM 树模型设计与防过拟合约束

### 2.1 为什么选择 LightGBM
- **非线性树分裂**：决策树通过阈值切分（如 `if funding_rate_zscore < -1.2 and rsi_14 < 32 then ...`）天然学习特征间的非线性协同效应，有效剔除线性模型中的“伪高分信号”；
- **训练极快、开销低**：在开发机（Ryzen 9 7945HX, 32GB RAM）上单次训练仅需数百毫秒，保证快速迭代与参数探索；
- **原生支持类别/连续特征与缺省处理**：数学性质优良，对特征缩放不敏感。

### 2.2 防过拟合（过拟合控制是量化研究的生命线）
金融时间序列噪声极大，深度过大的树极易过拟合训练集（2022—2024）。本方案制定严格的浅树、保守正则化配置：
1. **严格浅树**：限制树的最大深度 `max_depth` 在 2 ~ 4 之间，叶子节点数 `num_leaves` 限制在 4 ~ 15，坚决禁止深树（深度$\ge 6$）；
2. **叶子最小样本数**：`min_child_samples` 设为 50 ~ 100（每个叶子节点必须覆盖至少50~100个小时线样本支持），防止拟合局部孤立噪声；
3. **特征与样本随机采样**：`colsample_bytree = 0.8`, `subsample = 0.8`，每棵树随机采样80%特征与样本，提高泛化能力；
4. **保守学习率**：`learning_rate = 0.03 ~ 0.05`，配合适度树棵数（50 ~ 100棵）。

### 2.3 候选模型网格（3币 × 3组超参数 = 9个模型）
对比第一轮与第二轮的3组正则化参数（C=0.1, 1.0, 10.0），本轮设立3组不同保守程度的树复杂度超参数：
- **Candidate 1（极保守浅树，Ultra-Conservative）**：
  - `max_depth = 2`, `num_leaves = 4`, `min_child_samples = 100`, `n_estimators = 60`, `learning_rate = 0.05`
- **Candidate 2（均衡适中树，Balanced）**：
  - `max_depth = 3`, `num_leaves = 7`, `min_child_samples = 80`, `n_estimators = 80`, `learning_rate = 0.05`
- **Candidate 3（多层表达树，Expressive）**：
  - `max_depth = 4`, `num_leaves = 12`, `min_child_samples = 60`, `n_estimators = 100`, `learning_rate = 0.03`

BTC、ETH、SOL三币分别训练这3组候选，共持久化9个独立模型文件。

## 3. 特征与样本输入边界

- **特征输入**：沿用第二轮已验证的12项特征（9项价格量能均线指标 + 3项币安公开资金费率指标）：
  - 价格量能：`return_1h`, `return_4h`, `return_24h`, `volatility_24h`, `volume_ratio_24h`, `ma_cross_fast`, `ma_cross_slow`, `rsi_14`, `atr_pct_14`；
  - 资金费率：`funding_rate_latest`（前向对齐最新费率）、`funding_rate_ma3`（近3期平滑费率）、`funding_rate_zscore`（30天相对偏离度）。
- **训练样本来源**：直接沿用已归档并校验的 `EXP-021` 训练样本集（2022-01-01 至 2024-12-31，三币各6,387条有效样本，严格无未来泄漏）。
- **标签定义**：`target_up_4h`（未来4小时价格涨幅是否超过 0.15% 双边摩擦底线）。

## 4. 2025独立盲考验证回测与筛选规则

- **验证区间**：2025-01-01 00:00 UTC 至 2025-12-31 20:00 UTC（整整1年，8,757小时线，末端仅开盘清算）。
- **资金与风控默认值（保持严格一致）**：
  - 初始资金：100 USDT，三币共用同一账本；
  - 单笔开仓上限：25 USDT；总持仓上限：75 USDT；
  - 本金硬底线：固定 50 USDT，一旦触发立即止损平仓并锁定永久不再开仓；
  - 单笔止损：8% 价格硬止损；
  - 交易冷却：4小时；
  - 模拟成本：base费率（开平各0.075%，双边合计0.15%）。
- **阈值测试网格**：对每个模型测试概率阈值 `threshold = [0.55, 0.60, 0.65]`（共 9 模型 × 3 阈值 = 27 组回测，或精简关注 0.60 与 0.65）。
- **硬性通过门槛**：
  1. `net_return > 0`（扣费后净收益为正）；
  2. `max_drawdown <= 0.25`（最大回撤 $\le 25\%$）；
  3. `floor_triggers == 0`（50 USDT底线触发次数为0）；
  4. `closed_cycles >= 30`（闭合交易周期数 $\ge 30$ 笔，满足统计显著性检验）。
- **隔离底线**：若无模型通过全部4项门槛，坚决维持封存2026测试集，绝不提前解封。
